# VA3UJF Repeater Controller

This repository contains the source code for the VA3UJF Repeater Controller.

VA3UJF is a homebrew repeater built by [Evan Pratten](https://ewpratten.com) located in Burlington Ontario, Canada.

## Features

VA3UJF is a D-STAR repeater that supports multi-protocol links. Features include:

 - Memory-safe D-STAR packet handling
 - Automatic link management
 - AllStarLink bridges
 - EchoLink links
 - Natural language voice commands 
 - A live web UI, and Prometheus metrics at `/metrics` on the same port

## Use & Contributions

The repeater controller is only designed to support the VA3UJF repeater. That being said, anyone is welcome to try running the controller with their own hardware.

This repository is a public push-mirror of a segment of my personal projects monorepo. As such, pull requests are not accepted here.

If you would like to contribute a patch, please email me at the address [on my website](https://ewpratten.com).
